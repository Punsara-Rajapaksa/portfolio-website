# Punsara Rajapaksa Portfolio

Single-page portfolio website with a minimal modern UI, responsive layout, and subtle reveal animations.

Includes:

- Light and dark mode toggle with persistence
- Interactive WebGL hero canvas scene (Three.js)
- Media lightbox for project screenshots and videos
- Back-to-top button and scroll progress indicator
- Custom cursor, spotlight effect, and magnetic hover interactions
- Offline caching via service worker

## Current setup

- Home, About, Projects, Skills, Experience, Contact sections
- Resume download button
- Contact links with mailto, GitHub, and LinkedIn
- Project details for Clovio and BuildWith AI

## File map

- index.html: Content and section structure
- styles.css: Full visual system and responsive behavior
- script.js: Mobile menu and reveal animations
- hero-webgl.js: Real WebGL hero scene renderer
- service-worker.js: Asset caching for faster reloads and resilience
- assets/Punsara-Rajapaksa-Resume.pdf: Downloadable resume
